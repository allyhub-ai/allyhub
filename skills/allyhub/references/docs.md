# references/docs.md

A doc is a folder with a `doc.mdx`, which the person edits in an editor like Notion's. It renders to PDF and Markdown.

`allyhub help docs` lists the commands in order and prints where the SDK's `docs.md` is. Read it before writing a doc.

## See and measure

`allyhub check` finds errors. `allyhub frames` does not draw a doc: to see its pages, or how many there are, run `allyhub render --type png` into a working folder. That is a look, not a delivery.
