# references/reports.md

A report is a page that presents results, read on a screen and sent as a link, which you write freely in HTML, CSS and JavaScript: research findings, an account's snapshot, a review of customers' words, a market scan, a KPI review. The person downloads it as a PDF, a picture or one HTML file, or shares it as a link in Studio.

- `allyhub help reports` lists the commands and prints where the SDK's `reports.md` is.
- When the person names no style, write it by `allyhub report style show allyhub`.
- Its numbers may be read from the project: a sheet's tables, names and cells by reference, a data file by its path.
- `allyhub check` finds errors. Don't render, screenshot or export a report to see how it looks unless the person asks.
