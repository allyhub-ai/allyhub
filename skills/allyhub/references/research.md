# references/research.md

Cloud tools return data, not pages. They need no project.

## Find a tool

1. `allyhub help researching` lists the groups.
2. `allyhub <group>` lists a group's tools.
3. `allyhub help <group> <tool>` gives a tool's options and how its credits are counted.
4. `allyhub <group> <tool>` runs it.

## What each group holds

The catalog grows, so `allyhub <group>` is what there is now.

| Group        | Sources                                                                                              | Data                                                                                                                           |
| ------------ | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `social`     | TikTok, YouTube, Instagram, Facebook, X, LinkedIn, Reddit, Threads, Pinterest, Douyin, Xiaohongshu   | Profiles, posts, videos, comments, transcripts, followers, hashtags, sounds, trends                                            |
| `ads`        | Meta, Google, LinkedIn, TikTok ad libraries                                                          | Ads, advertisers, an advertiser's ads, ad transcripts on Meta                                                                  |
| `seo`        | Google search and AI answers                                                                         | Keyword metrics and trends, a site's keywords and gaps, backlinks, site and page audits, AI answers, AI mentions, web mentions |
| `web-search` | Google                                                                                               | Web, news, images, videos, Scholar, patents, suggestions                                                                       |
| `ecommerce`  | Amazon, Walmart, eBay, Etsy, TikTok Shop, Home Depot, Wayfair, Facebook Marketplace, Google Shopping | Products, prices, reviews, sellers, best sellers, Amazon keyword demand                                                        |
| `app-stores` | App Store, Google Play                                                                               | Apps, charts, reviews, keywords and gaps, competitors                                                                          |
