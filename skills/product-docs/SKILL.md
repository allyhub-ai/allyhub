# Product docs

## Goal

The documentation of one feature of a product, explaining it fully, with pictures of the product's interface at the key steps and annotations that mark what the text describes.

## Process

1. Research the product and the feature, and use it as a user would; at a login wall, ask the person to sign you in, then go on.
2. Rebuild the screens the docs need as reusable UI components in the project, or reuse those the project already has.
3. Write the docs, with the interface, annotated, at the key steps.
